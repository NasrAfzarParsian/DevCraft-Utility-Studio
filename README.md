## ✨ Features

- 🎨 **CSS Box Shadow Studio:** Visually adjust offset, blur, spread, color, and inset settings with real-time CSS code export.
- 🌈 **Gradient Designer:** Build custom linear and radial CSS gradients, add multiple color stops, and copy output instantly.
- 📝 **Live Markdown Editor:** Write Markdown on the fly with side-by-side formatted preview and HTML output viewing.
- 📋 **Task & Habit Tracker:** Stay productive with an integrated task manager that persists data locally using `localStorage`.
- 🌓 **Dark / Light Mode:** Modern dark theme by default with a quick toggle for light mode.
- ⚡ **Zero Setup Required:** Built as a self-contained, single-file lightweight application. No build step or dependencies needed!
